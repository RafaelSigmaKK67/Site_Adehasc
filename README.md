# ADEHASC Site

Portal público com painel ADM para matérias com texto, fotos e vídeos.

## Desenvolvimento

```powershell
npm.cmd install
npm.cmd run dev
```

Configure `ADMIN_PASSWORD` no Netlify antes de usar o painel `/admin` online.

Para teste local com `npm.cmd run dev`, a senha do painel ADM é:

```text
adehasc-admin-local
```
